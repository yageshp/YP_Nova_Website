# Google Business Profile — checklist for YP Nova

automatically improve rankings; a complete, accurate and active profile with genuine reviews helps over time.

## 1. Set it up as a service-area business (no walk-in office)
YP Nova has no customer-facing office, so:
- [ ] At https://business.google.com choose **"No"** when asked whether customers can visit a location (or later: *Business information →
      Location → Business location → remove/hide address*).
- [ ] Add **service areas**: **India** (Google lets you choose a country/region). YP Nova also works with international clients remotely —
      say so in the business description rather than adding foreign areas, since the profile is for local Google Maps visibility.
- [ ] Google may still ask for a postal address **privately for verification**; it stays hidden from the public when the profile is a
      service-area business. Do not use the residential map pin as a public business address.
- [ ] Do not create a second listing for the same business, and do not claim the existing "Green Meadows By Qualcon" place as YP Nova.

## 7. Add genuine images

## 8. Request reviews from real customers
- [ ] *Ask for reviews* → copy the review link → send it personally to clients you have actually worked with.
- [ ] No incentives, no reviews from staff/family, no review-exchange schemes. Reply to every review, positive or critical.
- [ ] Do not copy reviews onto the website's structured data.

## 9. Keep it active
- [ ] Post an update monthly (new Insights article, a new demo, a delivered project with permission).
- [ ] Answer questions in *Q&A* and messages promptly.
- [ ] Keep hours/holidays accurate if you publish hours.

## 10. Monitor performance
*Performance* (monthly): searches that showed the profile, views, website clicks, calls. In GA4 (when enabled) these appear as visits from
Google Maps / "google / organic" and `contact_phone_click` events.
